# 한길 인사·근태 관리 (사내망 전용)

직원명부와 근무시간보고서를 하나로 연동한 인사·근태 관리 웹 프로그램입니다.
공드럼 입출고 관리 앱과는 완전히 별개이며, 회사 PC 한 대를 서버로 쓰고 사내 네트워크 안에서만 접속합니다.

## 무엇을 할 수 있나요

| 메뉴 | 내용 |
|---|---|
| 현황 | 재직 인원, 외국인 근로자, 체류만료 임박자, 오늘 근태 입력 현황, 부서별 인원·근무시간, 확인이 필요한 정보 |
| 인사기록부 | 직원 추가·수정·퇴사 처리, 근속기간·생년월일·나이·체류만료 D-day 자동 계산, 주민번호 가림 표시 |
| 일일 근태 | 날짜별 근태 입력(정상·지각·조퇴·결근·연차·반차 등), 근무·연장시간 자동 계산, **근무시간보고서 인쇄**(문서번호 HG-26-A-02 양식, 결재란 포함) |
| 월간 근태 | 직원별 근무일수·근무시간·연장·지각·조퇴·결근·연차 집계와 1~31일 달력표, 인쇄·엑셀 저장 |
| 인사변동 | 입사·퇴사·부서이동·승진·체류만료 변경이 자동 기록, 직접 추가도 가능 |
| 설정·데이터 | 기본 출퇴근시각·휴게시간, 선택 목록, 엑셀 가져오기/내보내기, 암호화 백업·복원, 비밀번호 변경 |

**연동:** 인사기록부에서 `근태대상`으로 체크한 재직자만 일일 근태와 근무시간보고서 명단에 나옵니다. 퇴사 처리하면 명단에서 바로 빠집니다. 근태 입력 결과는 현황·월간 근태에 바로 반영됩니다.

## 보안

- **암호화:** 주민등록번호·연락처·주소를 포함한 모든 인사 데이터는 브라우저에서 **AES-256-GCM**으로 암호화한 뒤 서버로 보냅니다. 키는 관리 비밀번호로부터 PBKDF2-SHA256(12만 회)으로 만듭니다.
  서버 PC의 `data/` 폴더에는 **암호문만** 저장되고, 서버는 비밀번호와 복호화 키를 알지 못합니다.
- **사내망 전용:** 서버는 사설 IP 대역(`10.x`, `172.16~31.x`, `192.168.x`)과 서버 PC 자신(localhost)에서 온 접속만 받습니다. 그 밖의 주소는 403으로 거절합니다. 공인 IP 대역은 설정으로도 허용할 수 없습니다.
- 비밀번호를 5번 이상 틀리면 해당 PC는 1분부터 시작해 최대 1시간까지 점점 길게 잠깁니다.
- 일정 시간(기본 15분) 사용하지 않으면 자동으로 잠깁니다.
- 화면에서 주민번호는 기본으로 가려져 있고, `주민번호 보기`를 누르면 1분간만 보입니다.
- 엑셀 내보내기 파일은 암호화되지 않습니다. 기본으로 주민번호 뒷자리를 가리니, 외부로 보내지 마세요.

> 비밀번호를 잊으면 데이터를 복구할 수 없습니다. 비밀번호는 안전한 곳에 적어 두고, `설정·데이터 → 암호화 백업 저장`으로 주기적으로 백업하세요.

## 설치 (서버로 쓸 PC 한 대)

1. **파이썬 설치:** https://www.python.org/downloads/ 에서 Python 3을 설치합니다. 설치 화면에서 `Add python.exe to PATH`를 체크하세요. 추가 패키지 설치는 필요 없습니다.
2. 이 `hangil-hr` 폴더를 서버 PC의 원하는 위치(예: `C:\hangil-hr`)에 복사합니다.
3. `start_server.bat`을 더블클릭합니다. 검은 창에 접속 주소가 나옵니다.
   ```
   서버 PC에서:   http://localhost:8080
   사내 다른 PC:  http://192.168.0.10:8080
   ```
4. 윈도우 방화벽 창이 뜨면 **개인 네트워크만** 허용하세요. 공용 네트워크는 체크하지 마세요.
5. 처음 접속하면 관리 비밀번호(8자 이상)를 정하는 화면이 나옵니다.
6. `엑셀 파일 선택`에서 **직원명부**와 **근무시간보고서** 엑셀을 함께 선택하면 인사기록부·근태 명단·변동이력이 자동으로 만들어집니다.

서버 창을 닫으면 접속이 끊깁니다. PC를 켤 때 자동으로 실행하려면 `start_server.bat`의 바로가기를 `shell:startup` 폴더에 넣으세요.

## 설정 바꾸기 (선택)

`config.example.json`을 `config.json`으로 복사해 고칩니다.

```json
{
  "port": 8080,
  "allow": ["192.168.0.0/24"]
}
```

- `port`: 접속 포트
- `allow`: 접속을 허용할 사내 IP 대역. 예를 들어 사무실 대역만 허용하려면 `192.168.0.0/24`처럼 좁혀서 적습니다.

명령줄로도 바꿀 수 있습니다: `python server.py --port 9000 --allow 192.168.0.0/24`

## 데이터와 백업

| 위치 | 내용 |
|---|---|
| `data/vault.json` | 암호화된 인사 데이터 |
| `data/meta.json` | 암호화 설정(솔트, 접속 확인용 해시). 비밀번호는 들어 있지 않음 |
| `data/backups/` | 저장할 때마다 남는 자동 백업 (최근 300개) |

- 다른 PC로 옮길 때는 `data` 폴더째 복사하면 됩니다.
- 여러 PC에서 동시에 열어도 됩니다. 다른 PC가 먼저 저장하면 최신 내용으로 다시 불러오고 알려 줍니다.
- 비밀번호를 잊었을 때는 서버 PC에서 `http://localhost:8080`으로 접속해 로그인 화면의 `비밀번호를 잊었나요?`에서 저장소를 초기화할 수 있습니다. 모든 데이터가 지워지며, 이전 파일은 `data/reset-날짜` 폴더로 옮겨 둡니다.

## 구성 파일

```
hangil-hr/
├─ server.py            서버 (파이썬 표준 라이브러리만 사용)
├─ start_server.bat     윈도우 실행 파일
├─ start_server.sh      리눅스·맥 실행 파일
├─ config.example.json  설정 예시
└─ static/
   ├─ index.html, app.js, app.css   화면
   └─ vendor/
      ├─ hrcrypto.js    암호화 (noble-ciphers 1.3.0, noble-hashes 1.8.0 / MIT, hrcrypto.entry.js를 esbuild로 묶음)
      └─ xlsx.full.min.js  엑셀 읽기·쓰기 (SheetJS 0.18.5 / Apache-2.0)
```

인터넷 연결 없이도 동작하도록 외부 라이브러리는 모두 `vendor` 폴더에 들어 있습니다.
