성경 선택

검색

여러 단어를 띄어 쓰면 모두 포함된 구절을 찾아요. 요 3:16, 창 1, John 3처럼 입력하면 바로 이동해요.

즐겨찾기 · 형광펜

설정

기본으로 저작권이 만료된 개역한글과 KJV가 들어 있어요. 개역개정과 NIV는 저작권이 있는 번역본이라 앱에 포함할 수 없어서, 정식으로 구한 본문 파일을 아래에서 불러오면 이 기기에만 저장되어 쓰여요.
불러올 수 있는 파일 형식

UTF-8 또는 EUC-KR 인코딩의 텍스트(.txt/.csv/.tsv) 또는 JSON 파일을 지원해요.

1) 한 줄에 한 구절 (책 이름 + 장:절 + 본문)

창1:1 태초에 하나님이 천지를 창조하시니라
창 1:2 …
Genesis 1:1 In the beginning God created …
Gen 1:2 …

2) 구분자(탭, 쉼표, |)로 나눈 4칸 — 책은 번호(1~66)나 이름

1	1	1	태초에 하나님이 …
John,3,16,For God so loved the world …

3) JSON

{"books":[ [ ["1장1절","1장2절"], ["2장1절"] ], … ]}
[{"book":1,"chapter":1,"verse":1,"text":"…"}, …]
[{"name":"Genesis","chapters":[["…","…"]]}, …]
