# 나의 성경 (한글·영문 대조 성경)

`bible/index.html` 하나로 동작하는 대조 성경 웹앱입니다. 휴대폰에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있고, 한 번 열면 오프라인에서도 읽을 수 있습니다.

## 기능
- 한글/영문 구절별 대조 보기 (좌우 나란히 · 위아래 · 한글만 · 영문만)
- 책·장 선택, 이전/다음 장 (좌우 스와이프, ←/→ 키)
- 검색 (여러 단어 AND 검색), `요 3:16` · `창 1` · `John 3:16`처럼 입력하면 바로 이동
- 구절을 눌러 형광펜(4색) · 즐겨찾기 · 복사(한/영 함께)
- 글자 크기, 밝게/어둡게 테마, 마지막으로 읽은 위치 기억
- 즐겨찾기·형광펜 백업/복원

## 번역본
- 기본 내장: **개역한글**(1961), **KJV** — 저작권이 만료된 본문 (`data/krv.json`, `data/kjv.json`)
- **개역개정**(대한성서공회)과 **NIV**(Biblica)는 저작권이 있어 저장소에 넣을 수 없습니다.
  정식으로 구한 본문 파일을 앱의 **설정 → 번역본 → 파일 불러오기**로 넣으면
  그 기기(브라우저)에만 저장되어 기본 번역본 대신 표시됩니다.

지원 형식(UTF-8/EUC-KR): `창1:1 본문`, `Genesis 1:1 text` 같은 한 줄 한 구절 텍스트,
`책,장,절,본문` 형태의 CSV/TSV, 또는 JSON(`{"books":[[["1:1","1:2"],…],…]}` 등).

## 로컬 실행
본문을 `fetch`로 읽기 때문에 파일을 직접 열지 말고 웹 서버로 열어야 합니다.

```bash
python3 -m http.server 8000
```
그 뒤 http://localhost:8000/bible/ 접속.
